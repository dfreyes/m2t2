1. DIAGNÓSTICO DEL ESQUEMA Y TIPOS DE DATOS (DATA TYPES)
------------------------------------------------------------------
El mapeo de datos desde Pandas hacia SQLite ha estructurado la tabla 'ventas_retail' utilizando tres tipos de almacenamiento principales: TEXT, INTEGER y REAL. A continuación se describe el significado técnico y analítico de esta estructura:

* TEXT (Cadenas de caracteres):
  - 'InvoiceNo' y 'StockCode': Son llaves alfanuméricas maestras. Se almacenan como texto porque pueden contener letras (ej. prefijos 'C' de cancelaciones o letras de inventario).
  - 'Description' y 'Country': Datos categóricos puros descriptivos.
  - 'AUX1' y 'AUX2': Campos de auditoría de texto para aislar sufijos y transacciones atípicas.
  - 'AñoMes' y 'Fecha': Almacenados como texto (formato ISO/estándar). SQLite no posee un tipo de dato 'DATE' nativo, por lo que convertirlos a TEXT es la mejor práctica para garantizar filtros alfabéticos ordenados consistentes.

* INTEGER (Números enteros discretos):
  - 'Quantity': Cantidades físicas de productos comprados o devueltos.
  - 'InvoiceNo_C': Variable binaria (indicador o flag) donde 1 es Cancelado y 0 es Normal.
  - 'Hora': Variable numérica de tiempo discreto (0 a 23).

* REAL (Números de punto flotante / decimales):
  - 'UnitPrice': Precio unitario del producto. Requiere precisión decimal.
  - 'CustomerID': Almacenado como REAL debido a la presencia de valores nulos (NaN en Pandas se traduce a floats). Esto es un comportamiento normal de conversión de tipos.
  - 'InvoiceNoN' y 'StockCodeV': Almacenados como REAL en SQLite para poder retener compatibilidad con celdas vacías del dataset original.

* TIMESTAMP (Fecha y hora con zona horaria):
  - 'InvoiceDate': Conserva la estampa de tiempo transaccional exacta para análisis cronológico detallado.

* Restricciones (Obligatorio y dflt_value):
  - Todas las columnas muestran 'Obligatorio = 0' y 'dflt_value = None', lo que significa que la tabla es flexible en base de datos: permite celdas vacías (NULL) sin restricciones de obligatoriedad (NOT NULL) ni valores por defecto aplicados a nivel de motor.

------------------------------------------------------------------
* Volumen Total (Total_Filas: 541,909):
